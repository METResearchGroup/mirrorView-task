# Participant decision rules

We have a list of possible standards and criteria that people use when considering their moderation decisions. However, participants may apply different combinations of those standards and for different cases in practice.

Here, we're interested in created a "behavioral profile" for each participant.

(We can use that criteria to create labels for each post, like "removing this post is unfair")

(given that, we can look at all the posts they actually moderated)

(we can collect them and see why they chose what they did).

(we can also consider things like overall removal rate, removal rate by toxicity group, removal rate for politically aligned and opposed posts, and sensitivity to the language features already discovered)
