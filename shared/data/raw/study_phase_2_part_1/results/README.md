# Study Phase 2, Part 1

This contains the data from a data collection round of 2,000 users across the 3 study conditions from Phase 2, Part 1 (see [History of Study](docs/runbooks/HISTORY_OF_STUDY.md)).

- `pilot.csv`: contains records from the pilot run.
- `full.csv`: contains the records from the full study collection run.
- `claude_generated_mirrors.csv`: contains the stimuli shownn to study participants.
