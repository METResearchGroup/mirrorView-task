# Part 3 keep/remove labels

One row per rated Study Phase 2 Part 3 post. Modal decision from linked-fate keep/remove trials. Ties are `remove`.

Generated by `transform.py`. Registered as `STUDY_PHASE_2_PART_3_KEEP_REMOVE_LABELS`.

```bash
PYTHONPATH=. uv run python shared/data/transformed/study_phase_2_part_3/transform.py
```

`load_dataset` reads the materialized CSV from S3 at the registry key. Upload after regenerating locally.

`is_unanimous` is true or false when a post has at least two raters, and blank when it has one. The min-3-rater filter is not applied here.
