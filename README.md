## What is MirrorView

Review [WHAT_IS_MIRRORVIEW](docs/runbooks/WHAT_IS_MIRRORVIEW.md) and [HISTORY_OF_STUDY](docs/runbooks/HISTORY_OF_STUDY.md) to learn more about this project.

We have two important workflows here:

- `webapp/`: the web app that we deploy and show to users.
- `experiments/`: experiments, exploration, and other code to analyze study data and perform ablations.
